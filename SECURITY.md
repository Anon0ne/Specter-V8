# Security reports

Report vulnerabilities privately to **justin@bizhostnc.com** with the subject
`Specter V8 security report`. Include source revisions, reproduction steps and a
minimal sanitized example. Do not publish unpatched exploit details or include
passwords, tokens, license keys or private captures in public issues.

The beta is experimental; see `docs/PUBLIC_BETA.md` for known limitations. Successful builds, scanners and tests do not establish that a release
has no vulnerabilities. Third-party components retain their own licenses.
